# ITEM 024.b

A scroll-driven presentation of ITEM 024.b, a work in progress by GM Architects: a leaf's path through turbulent air,
traced into a curve and shaped into a suspended, ribbed light.

- **Scrolling version:** https://tarekcmahmoud.github.io/item24.b/
- **Autoplay version:** https://tarekcmahmoud.github.io/item24.b/autoplay.html (one scroll, swipe or key starts it; add `?debug` to the address for the speed slider)

## How it works

A static site with no build step: two self-contained HTML pages (the flow, the curve, the form and the room are drawn
live in WebGL), the renders as images, and nothing else. Any static host can serve it.

- `index.html` – the scrolling version
- `autoplay.html` – the self-playing version
- `context.jpg`, `view-1.jpg`, `view-2.jpg`, `view-3.jpg` – the renders
- `preview.jpg`, `favicon.svg` – the link preview and the tab icon
